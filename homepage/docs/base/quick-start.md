# 新手教程

可以按照下面的步骤, 来一步步了解社区或参与社区活动

## 0.参与社区活动

> 社区提供了群组、论坛等形式, 可以用于社区和C++相关内容的交流讨论

### `0.0-加入社区:` 群组1067245099, [社区论坛](https://forum.d2learn.org/category/20), [开源org成员申请](https://github.com/orgs/mcpp-community/teams/members)

### `0.1-参与社区讨论` 在论坛参与C++相关话题讨论, 或发布新话题贴或文章

  - 常见话题: C++技术问题、社区项目、C++生态等
  - 常见文章类型: 技术文章、工程/开发记录、心得等

## 1.使用社区项目

> 社区中的项目分为了 教程类 和 C++库类型. 教程项目可以用来学习现代C++相关的技术/知识, 工具库类项目 可以用来辅助和提升自己项目的开发

### `1.0-学习C++相关知识`

  - [mcpp-start | 基础编程概念和现代C++](./quick-start.md)
  - [mcpp-style-ref | 现代C++模块化编码/项目风格参考](https://github.com/mcpp-community/mcpp-style-ref)
  - [d2mcpp | 现代C++核心特性入门](https://github.com/mcpp-community/d2mcpp)
  - [d2mystl | 从零开发迷你STL标准库](https://github.com/mcpp-community/d2mystl)

### `1.1-使用社区mcpplibs库`

  - [llmapi | 支持模块化的大模型API库](https://github.com/mcpplibs/llmapi)
